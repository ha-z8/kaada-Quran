# تخطيط أسطر مصحف المدينة — وِرد V3

أضيف محرك واجهة لعرض أسطر الصفحات المستوردة محليًا؛ **لم تُدمج بيانات أسطر مصحف المدينة الرسمية بعد**.

## شكل البيانات المتوقع
أنشئ الملف `data/layout-lines.json` اعتمادًا على ملفات حصلت على إذن توزيعها:

```json
{
  "version": 1,
  "source": "Authorized dataset name, edition, revision and license",
  "pages": {
    "1": [
      {"type":"surah-header","text":"سورة الفاتحة"},
      {"type":"text","text":"نص السطر بالرسم العثماني"}
    ]
  }
}
```

يجب أن تتضمن `pages` المفاتيح 1 إلى 604، وأن يتطابق المحتوى مع إصدار الخط وبيانات السطر، ويُراجع على كامل المصحف. حتى توفير هذا الملف تظل الواجهة تستخدم النص العثماني الموجود مع حدود الصفحات، لكنه **ليس تنضيد أسطر مصحف المدينة**.

للحصول على البيانات الأصلية راجع: https://qurancomplex.gov.sa/quran-dev/ . توجد حقول `line_start` و`line_end` للأيّات؛ لكنها ليست بمفردها كافية لاستخراج حدود كل كلمة على السطر. وتوضح Quran Foundation كيفية تجميع الكلمات حسب رقم السطر: https://api-docs.quran.foundation/docs/tutorials/fonts/page-layout/ . تحتاج بعض الواجهات إلى مصادقة وشروط مطورين.

لا تنسخ مخزونًا خارجيًا غير مرخّص إلى هذا المستودع. واجب فحص النص وحزم الخطوط وصحة ترقيم الآيات والصفحات قبل إطلاق نسخة مطابقة للمصحف.
