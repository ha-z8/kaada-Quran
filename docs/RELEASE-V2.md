# وِرد — سجل الإصدار 2 (2026-10-31)

## نُفذ
- تحديث التصميم المتجاوب لصفحات القرآن والأذكار.
- تحسين منتقي الخطوط الثلاثة (النسخ العثماني، الخط الرقمي، حفص) مع ملفات WOFF2 محلية.
- تحسين عرض صفحات المصحف الـ604 اعتمادًا على بيانات حدود الصفحات.
- تحسين بطاقات حصن المسلم مع مرجع الذكر ومؤشر الإتمام.
- حفظ عدادات التسبيح والمفضلة محليًا على جهاز المستخدم.
- ضبط Service Worker لتخزين ملفات القرآن وحصن المسلم والخطوط والصفحات محليًا وتنظيف التخزين القديم.
- البحث القرآني المحلي ومرجع السورة/الآية والبحث في الأذكار.
- فحص صياغة JavaScript الأساسية ووجود 133 بابًا و302 ذكرًا.

## حدود النسخة الحالية
- **ليس** عرضًا مطابقًا لـ15 سطرًا من المصحف الورقي. يلزم بيانات خطوط وكلمات/أسطر QCF مطابقة للإصدار مع حق استعمال واضح.
- لا يتضمن التفسير الميسر، معاني الكلمات، الترجمات، أو التلاوات الصوتية محليًا بعد.
- تغيير نوع خط العرض لا يعادل التبديل بين طبعات مصحف المدينة QCF V1/V2؛ لكل طبعة خط وبيانات تخطيط متوافقة.
- لم يتم إجراء اختبار مرور شامل في متصفحات متعددة أو التحقق الفعلي من انقطاع الاتصال بعد إعادة تشغيل الجهاز.
- بيانات حصن المسلم من مشروع طرف ثالث مرخّص MIT؛ لا تُنسب إلى جامعة أم القرى أو مجمع الملك فهد.
- يلزم مراجعة علمية للنصوص المنقولة قبل ادعاء التدقيق الشرعي الكامل.

## التشغيل
يشترط فتح الموقع أول مرة عبر HTTPS حتى يخزّن Service Worker الموارد اللازمة. بعد نجاح تخزين جميع ملفاتها، يمكن استعمال وظائف القراءة والأذكار دون اتصال، ما دام المتصفح لم يحذف بيانات التطبيق. افتح إعدادات الموقع/التطبيق للتحقق من التخزين وعدم حذفه.
