# وِرد 6 | WIRD — القرآن الكريم والأذكار

مصحف إلكتروني عربي موحد في التصميم يضم القرآن الكريم، حصن المسلم، مسبحة إلكترونية، إعدادات الخط والمظهر، العلامات المرجعية، والتلاوات الصوتية. يتضمن شعارًا خاصًا بوِرد، ويعرض شعار كلية الملك عبدالعزيز الحربية كما زُوّد للمشروع.

[افتح الموقع](https://kaada-quran.pages.dev) — [طريقة صناعة تطبيق ويندوز دون إنترنت](docs/WINDOWS-OFFLINE.md)

## المصحف
- 114 سورة، 6236 آية، 604 صفحات.
- **عرض مصحف المدينة QCF V2** بأسطر الصفحة الأصلية مع 604 ملف خط من مجمع الملك فهد وبيانات QUL؛ يدعم الضغط على كلمات الآيات لفتح الإجراءات.
- عرض «آية بآية» مع خطوط القراءة القابلة للتغيير والحجم.
- صفحة 1 والفاتحة، البسملة، الآيات والصفحات، التنقل والبحث وحفظ آخر موضع.
- الوصول المباشر إلى صفحة المصحف والتلاوات والمسبحة والأذكار.

## صوتيات القرآن
- **12 قارئًا** بملفات آيات مستقلة من EveryAyah؛ جرى فحص أول وآخر آية لكل قارئ مع السماح بتحميل الصوت من المتصفح.
- خيارات: آية واحدة / بقية السورة / إلى نهاية القرآن / تكرار الآية / سرعة التلاوة.
- **السديس ومحمد أيوب** صوتان افتراضيان كاملان في **حزمة ويندوز النهائية فقط**، عند بناء الحزمة باستخدام السكربت الذي يتحقق من كامل 6236 ملفًا لكل قارئ.
- موقع الويب يسمح بتنزيل تسجيلات سورة مختارة للاستماع دون اتصال، ولا يجبر الأجهزة الصغيرة على تنزيل تسجيلات القرآن كاملًا.
- تشغيل تسجيلات القراء الآخرين عبر الإنترنت أو ملفات السور التي حفظها المستخدم مسبقًا.

## تطبيق ويندوز
حمّل هذا المستودع ZIP على جهاز ويندوز متصل بالإنترنت، وثبّت Node.js 22+ على **جهاز البناء** وشغّل:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Make-Windows-Offline.ps1
```
يحمّل السكربت تسجيلات السديس ومحمد أيوب كاملةً (12472 ملف MP3)، ويتأكد من اكتمالها، ثم يُنشئ مُثبّت `.exe` ونسخة `Portable` وملفات `.zip` ZIP64 يمكن نقلها وتشغيلها على أجهزة Windows x64 بلا إنترنت أو Node.js.

**لإنشاء الحزمة من GitHub Actions**: افتح Actions ثم سير `WIRD 6 full offline Windows installer` واضغط Run workflow. هذا السير يدوي وقد يستهلك مساحة تخزين ومقدارًا كبيرًا من بيانات الشبكة، وقد يخضع لحصص حساب GitHub. ملفات التنزيل الصوتية ليست مضمنة في GitHub Code ZIP. لا تُوصف الحزمة النهائية بأنها مُجربة حتى يكتمل البناء والتثبيت على جهاز ثانٍ.

راجع [الدليل التفصيلي](docs/WINDOWS-OFFLINE.md).

## المصحف والأذكار دون اتصال
- يضم التطبيق ملفات القرآن والأذكار والخطوط الأساسية، ومحتوى مصحف المدينة الأصلي، ضمن حزمة ويندوز.
- على الويب: تحفظ PWA الملفات الأساسية؛ لعمل **جميع صفحات خط QCF** دون شبكة استخدم زر «حفظ جميع صفحات مصحف المدينة» في الإعدادات مع وجود مساحة كافية.
- حصن المسلم: 133 بابًا و302 ذكرًا، العداد والمفضلة والبحث.
- المسبحة الإلكترونية: أذكار متعددة وعداد مستقل لكل ذكر محفوظ على الجهاز.

## المصادر والحقوق
تُعرض المصادر في صفحة مستقلة داخل الموقع؛ أهمها:
- مجمع الملك فهد لطباعة المصحف الشريف: https://qurancomplex.gov.sa/quran-dev/
- خطوط صفحة مصحف المدينة QCF V2 وحقوقها محفوظة للمجمع؛ تخطيط الصفحة من QUL (المرآة: https://github.com/manaf/KFGQPC-Madinah-Mushaf ).
- Quran Foundation: https://quran.foundation/ ، وhttps://quran.com/ar/developers
- النص الأساسي: Al Quran Cloud؛ الصوت: EveryAyah؛ بيانات الأذكار: HisnElMuslim (MIT).

**تنبيه الحقوق**: لا تسمح كل المصادر بالضرورة بإعادة توزيع التسجيلات أو الخطوط بلا شروط. راجع تراخيص المصدر قبل نشر أو بيع نسخ كاملة، خصوصًا ملفات MP3 المستضافة خارجيًا. يقتصر استيراد QCF في هذا المشروع على الاستخدام التعليمي غير التجاري مع نسبة المصدر ودون تعديل نص القرآن.

## الفحوص
تشغّل GitHub Actions فحص صحة 604 ملفات QCF وخطوطها، بيانات الآيات والأذكار، واختبار Chromium للتنقل والمسبحة والبسملة والصوت المخزن، وفحص تغليف Electron على Windows. هذا لا يغني عن اختبار الملف النهائي على جهازين منفصلين بعد إتمام تنزيل الصوت.
