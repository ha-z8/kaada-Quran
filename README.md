# كعدة قرآن | KAADA Quran

مصحف عربي يعمل دون اتصال بعد تنزيل ملفات الموقع. يبدأ سير GitHub Actions بتحميل النص القرآني إلى `data/quran.json` والتحقق من اكتماله.

## التشغيل

```bash
python -m http.server 4173
```

ثم افتح `http://localhost:4173`.

**مهم:** لا تفتح `index.html` ببروتوكول `file://` لأن تحميل ملفات JSON وService Worker يتطلب خادم HTTP.

لن يعمل وضع القراءة حتى ينتهي سير `Prepare complete Quran data` بنجاح ويضيف ملف البيانات.

الواجهة بلا مكتبات خارجية، والقراءة والبحث والعلامات المرجعية كلها محلية. معلومات مصدر النص في `data/SOURCE.md`.
