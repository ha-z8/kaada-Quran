# خط واجهة وِرد — ارفع ملفك هنا

**مسار الخط:** `fonts/ui/site.woff2` (المفضّل) أو `fonts/ui/site.ttf`.

1. افتح هذا المجلد في GitHub: `https://github.com/ha-z8/kaada-Quran/tree/main/fonts/ui`.
2. اختر **Add file → Upload files**.
3. ارفع ملف خطك، وأعد تسميته **بالضبط** إلى `site.woff2` لو كان بصيغة WOFF2، أو `site.ttf` لو كان بصيغة TTF.
4. اضغط **Commit changes** على الفرع `main`.
5. Cloudflare يعيد النشر تلقائيًا، وخط واجهة وِرد سيظهر في جميع الأقسام عند تحديث المتصفح.

**مهم**: هذا خاص بخط الواجهة (القوائم والأزرار والعناوين والتقارير والإعدادات وحصن المسلم). خط الآيات وطبعة مصحف المدينة QCF V2 مستقل للحفاظ على الرسم العثماني وترتيب الأسطر، ولا يجوز استبداله بخط الواجهة.

إذا رفعت الخط باسم آخر أو بصيغة OTF، أعطني اسم الملف والصيغة لأعدّل الربط. لا ترفع خطًا لا تملك إذن استخدامه أو نشره.
